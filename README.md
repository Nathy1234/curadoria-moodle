# Curadoria Word × Moodle

Ferramenta para conferir questões importadas no Moodle: compara o Word original com o XML exportado do Moodle e gera um XML corrigido, com o espaçamento, o recuo, a entrelinha e as imagens como no Word.

## Como usar

1. Abra a página do GitHub Pages deste repositório.
2. Envie o Word original (.docx) e o XML exportado do Moodle (Banco de questões → Exportar → Formato Moodle XML).
3. Clique em **Comparar** e veja o relatório.
4. Clique em **Corrigir e baixar XML** e importe o arquivo baixado no Moodle (Banco de questões → Importar → Formato Moodle XML).

Os arquivos são lidos só no navegador de quem usa. Nada é enviado ou salvo em servidor.
